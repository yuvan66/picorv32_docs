System Memory Map

All peripherals are memory-mapped. The PicoRV32 CPU accesses them via standard load/store instructions. The upper nibble of the address selects the peripheral.

Base AddressEnd AddressSize PeripheralDescription
0x0000_00000x0000_07FF 2 KBBoot ROM Bootloader (preloaded from bootloader.hex). R/W by CPU.
0x1000_00000x1000_1FFF 8 KBApp RAM Application code + data. Written by bootloader at startup.
0x2000_00000x2000_0007 8 BUART Serial port — TX / RX data + status register.
0x3000_00000x3000_0003 4 BLED 16-bit LED output register.
0x4000_00000x4000_000B 12 BTimer 32-bit free-running counter + compare + control.
0x5000_00000x5000_000F 16 BTRNG True Random Number Generator — ring-oscillator based.
Note: Address decoding uses bits [31:28] (the upper nibble). Any unaligned access or unmapped address returns 0x00000000 and does not stall the bus.

1. UART 0x2000_0000

A simple 8-N-1 UART with a fixed baud rate of 115200 baud. The baud divisor is hard-coded to 868 clock cycles per bit (100 MHz ÷ 115200). TX and RX share the same DATA register address — direction is determined by read vs. write.

1.3 — C Usage Examples

// ── Transmit one byte ──────────────────────────────────
while (REG_UART_STATUS & 0x01); // wait TX_BUSY = 0
REG_UART_DATA = 'A';

// ── Receive one byte (blocking) ────────────────────────
while (!(REG_UART_STATUS & 0x02)); // wait RX_VALID = 1
char c = (char)(REG_UART_DATA & 0xFF);

// ── Non-blocking RX check ──────────────────────────────
if (REG_UART_STATUS & 0x02) {
    char c = (char)(REG_UART_DATA & 0xFF);
}

// ── Driver API shorthand ───────────────────────────────
uart_putc('H'); // blocks until TX_BUSY clears, then sends
uart_puts("Hello!\n"); // sends each char, auto-inserts \r before \n
char b = uart_getc(); // blocks until RX_VALID = 1

// ── Turn all LEDs ON ───────────────────────────────────
REG_LEDS = 0xFFFF;

// ── Turn all LEDs OFF ──────────────────────────────────
REG_LEDS = 0x0000;

// ── Light only LED 7 (bit 7) ───────────────────────────
REG_LEDS = (1U << 7);

// ── Toggle LED 3 without affecting others ──────────────
REG_LEDS ^= (1U << 3);

// ── Driver API ─────────────────────────────────────────
led_set(0xAAAA); // alternating pattern
led_toggle(0x00FF); // toggle lower 8 LEDs
led_set_bit(5); // set LED5 only
led_clear_bit(5); // clear LED5 only

3. Hardware Timer 0x4000_0000

A 32-bit memory-mapped hardware timer. At reset, the counter is enabled and free-runs at 100 MHz (10 ns per tick). When the counter reaches the compare value (TIMER_CMP), it resets to zero, sets the MATCH flag, and raises an IRQ.

Timing reference: 1 ms = 100,000 ticks  |  1 µs = 100 ticks  |  1 s = 100,000,000 ticks (0x05F5_E100)

3.4 — C Usage Examples

// ── Read raw tick count ────────────────────────────────
uint32_t now = REG_TIMER_CNT; // ticks since last match

// ── Spin-wait for 1 ms (100,000 ticks) ────────────────
uint32_t t0 = REG_TIMER_CNT;
while ((REG_TIMER_CNT - t0) < 100000);

// ── Set compare for 500 ms (50,000,000 ticks) ─────────
REG_TIMER_CMP = 50000000;
REG_TIMER_CTRL = 0x03; // EN=1, clear any prior match
while (!(REG_TIMER_CTRL & 0x04)); // poll MATCH flag (bit 2)
REG_TIMER_CTRL = 0x03; // clear MATCH after handling

// ── Stop the timer ─────────────────────────────────────
REG_TIMER_CTRL &= ~0x01; // EN = 0

// ── Driver API ─────────────────────────────────────────
timer_init(); // sets CTRL = 0x01 (enable)
uint32_t c = timer_get_cycles(); // reads CNT
timer_delay_cycles(100000); // spin-waits 1 ms
Warning: When CMP is set, the counter resets to 0 on match. If you use TIMER_CNT for timestamps (elapsed time measurement), set CMP = 0 to let the counter free-run indefinitely.

4. TRNG 0x5000_0000

A hardware True Random Number Generator based on a bank of 16 ring oscillators with lengths 3, 5, 7, ... 33 inverter stages. Output bits are XOR-combined, optionally de-biased using the von Neumann algorithm, and assembled into 32-bit words. Two NIST SP 800-90B health tests (Repetition Count + Adaptive Proportion) run continuously.

Startup sequence: Write TRNG_CTRL = 0x03 (EN + VN_EN), then wait for WARMUP_DONE (bit 4 of TRNG_STATUS) before reading data. The warm-up discards the first 1024 raw bits.

4.5 — C Usage Examples

// ── Standard startup (always do this first) ────────────
REG_TRNG_CTRL = 0x03; // EN=1, VN_EN=1
REG_TRNG_DIV = 0; // fastest sample rate
while (!(REG_TRNG_STATUS & 0x10)); // wait WARMUP_DONE

// ── Read one 32-bit random word (safe way) ─────────────
while (!(REG_TRNG_STATUS & 0x01)); // wait DATA_VALID
uint32_t r = REG_TRNG_DATA; // pops word, clears DV

// ── Check health before use ────────────────────────────
if (REG_TRNG_STATUS & 0x02) { // HEALTH_FAIL
    REG_TRNG_CTRL = 0x0B; // CLR=1 + EN=1 + VN_EN=1
    while (!(REG_TRNG_STATUS & 0x10)); // re-warm
}

// ── Disable to save power ──────────────────────────────
REG_TRNG_CTRL &= ~0x01; // EN = 0

// ── Driver API ─────────────────────────────────────────
trng_init(); // EN=1, VN_EN=1
while (!trng_is_warm()); // poll bit 4
uint32_t r = trng_read(); // blocks until DV=1, then pops
bool ok = trng_has_data(); // non-blocking DV check
Warning: Reading TRNG_DATA when DATA_VALID = 0 returns 0x00000000 — this is NOT a random value. Always poll DATA_VALID or use trng_read() which blocks until valid.

5. C Driver Quick Reference

All driver functions are in app/. Include the relevant header and link the corresponding .c file via the Makefile.

// ── UART (uart.h / uart.c) ────────────────────────────
void uart_putc(char c); // TX one byte (blocking)
void uart_puts(const char *s); // TX string (\n auto-adds \r)
bool uart_available(void); // true if RX_VALID = 1
char uart_getc(void); // RX one byte (blocking)
void uart_print_dec(uint32_t v); // print decimal number
void uart_print_hex32(uint32_t v); // print "0x12345678"

// ── LED (led.h / led.c) ───────────────────────────────
void led_set(uint16_t value); // set all 16 LEDs at once
void led_toggle(uint16_t mask); // XOR mask onto current state
void led_set_bit(uint8_t bit); // set single LED (0-15)
void led_clear_bit(uint8_t bit); // clear single LED (0-15)

// ── Timer (timer.h / timer.c) ─────────────────────────
void timer_init(void); // enable timer (CTRL = 0x01)
uint32_t timer_get_cycles(void); // read TIMER_CNT
void timer_delay_cycles(uint32_t n); // spin-wait n ticks

// ── TRNG (trng.h / trng.c) ────────────────────────────
void trng_init(void); // EN=1, VN_EN=1
bool trng_is_warm(void); // WARMUP_DONE (bit 4)
bool trng_has_data(void); // DATA_VALID (bit 0)
uint32_t trng_read(void); // blocking: waits DV, pops word
