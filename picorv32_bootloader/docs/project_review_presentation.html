2. Hardware Security Token & 2FA Authenticator Protocol

The SoC functions as a dedicated, physically isolated Hardware Security Token (analogous to a YubiKey or RSA SecurID hardware token) that prevents software-based password sniffing, PRNG prediction, and network replay attacks.

🛡️ 1. Physical Hardware Isolation

Host PCs can be infected with kernel malware, keyloggers, or background screen recorders. The FPGA node executes credentials entirely inside the isolated on-chip BRAM bus with zero host OS memory exposure.

Zero Software Leak: Private states and hardware entropy never exist in host RAM.

🎲 2. True Hardware Entropy (TRNG)

Standard software rand() uses deterministic seed math that attackers can easily reverse-engineer. The FPGA fabric samples physical phase jitter across 16 asynchronous ring oscillators with a hardware Von Neumann de-biaser.

Cryptographic Unpredictability: Physically impossible to seed or predict.

⏱️ 3. Hardware-Enforced 30s Time-To-Live

Sniffed network packets and intercepted OTPs are rendered useless by the 100 MHz Hardware Timer. The token expires exactly after 30 seconds (3,000,000,000 clock cycles), rejecting subsequent replay attempts.

Anti-Replay Defense: Expired tokens trigger instant hardware lockout.

3. Embedded Cooperative Multi-Task Scheduler

Traditional bare-metal code relies on blocking delay() calls that freeze CPU execution. To handle entropy harvesting, TTL timing, LED animations, and serial packet handling concurrently with deterministic latency, we designed a lightweight cooperative scheduler driven by the 100 MHz hardware timer tick base:

Task 1: TRNG Harvester 20 Hz (50 ms)
Periodically polls REG_TRNG_STATUS and pulls 32-bit random words into a 64-byte circular ring buffer. Ensures zero-latency availability of 128-bit cryptographic nonces.
Task 2: TTL Timer & LED Bar 10 Hz (100 ms)
Reads REG_TIMER_CNT and calculates elapsed time. Animates the 16 on-board LEDs as a linear progress bar and invalidates tokens past 30.00 seconds.
Task 3: UART Command Parser Async / 50 Hz
Non-blocking serial receiver checking UART_STAT_RX_VALID. Parses auth_req, auth_val, and raw entropy dump commands.
Task 4: Telemetry Monitor 1 Hz (1000 ms)
Formats and transmits live system health metrics, uptime seconds, total authentications, and ring buffer fill levels over the serial terminal.
